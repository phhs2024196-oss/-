# 팀에 일 시키는 법

프로젝트 채팅에서 **"팀이름: 할 일"** 형식으로 쓰면 기획실(코디네이터)이 해당 팀 스레드로 넘긴다.

| 팀 | 이렇게 말하면 됨 | 그 팀이 부르는 에이전트 |
|---|---|---|
| 문항팀 | `문항팀: 유유상종(유형별 N제) 미적분 20문항 출제` | item-writer → item-verifier → blind-solver → solution-writer |
| 디자인팀 | `디자인팀: 위 20문항 조판하고 표지 시안 2개` | typesetter, figure-maker, cover-designer |
| 품질보증팀 | `품질보증팀: 유유상종 1권 출간 전 검수` | proofreader, originality-checker, independent-auditor |
| 마케팅팀 | `마케팅팀: 오르비용 무료 샘플 글 초안` | content-marketer |
| 판매팀 | `판매팀: 스마트스토어 등록 초안` (2027-05~) | store-manager, cs-agent, distribution-agent |
| 채점사이트팀 | `채점사이트팀: MVP 답안 업로드 화면` | site-developer, grading-engine, grading-validator, site-ops |
| 기획실 | `기획실: 이번 주 진행 현황` / `기획실: DB 태그 정리` | db-librarian |

- 팀 스레드가 아직 없으면 기획실이 새로 연다. 팀당 동시 서브에이전트 4개 이하.
- 외부로 나가는 일(등록·가격·게시·발송)은 초안까지만, 실행은 대표 승인 뒤.
- 결과는 팀 스레드에 올라오고, 기획실이 프로젝트 채팅에 한 줄로 요약한다.
