# [002] 로블록스 플랫폼 게임 개발 및 수익화

- **카테고리**: 플랫폼 종속형 콘텐츠 개발 (게임/코딩)
- **상태**: 아이디어 (원본: 유튜브 콘텐츠 요약)
- **등록일**: 2026-09
- **출처**: 사용자 제공 — 유튜브 영상 "잼민이 게임으로 한달 연봉 10억 찍는 개발자들 (로블록스)" (코딩애플 채널)

## 한 줄 요약

로블록스 스튜디오로 게임을 만들어 플랫폼 내에서 직접 수익화하는 모델. 루아우(Luau) 언어 기반, 진입장벽이 낮아 초보자도 시작 가능하나 수익은 플랫폼 수수료 구조에 종속됨.

## 핵심 강점 (Fusion 재료)

- **S1. 낮은 진입장벽 + 원클릭 배포**: 로블록스 스튜디오만으로 별도 엔진 지식 없이 제작 가능, 배포 버튼으로 즉시 퍼블리싱 — 자체 배포 인프라/스토어 심사 불필요
- **S2. 거대 기성 유저풀 무료 접근**: 일접속자 1억명, 연매출 6조원 규모 플랫폼에 무료로 노출됨 — 별도 마케팅·서버 비용 없이 트래픽 확보
- **S3. AI 개발 가속 구조**: 3D 모델링 AI·AI 에이전트를 활용해 코딩/에셋 제작 시간을 단축할 수 있음 (1인 개발 생산성 극대화)
- **S4. 커리어 전이 가치**: 수익화에 실패해도 개발 경험 자체가 게임업계 취업 포트폴리오로 남음 — 리스크의 일부가 자산으로 전환됨
- **S5. 저비용 시장성 사전검증**: 유저의 실제 플레이/모드 반응으로 시장 수요를 먼저 확인한 뒤 투자를 늘리는 구조 (제작 전 대규모 리서치 불필요)

## 상세 설명

### 수치 근거 (NUM)
- 일접속자 1억명
- 연간 매출 6조원
- 개발자 수수료 구조: 로블록스 측이 매출의 약 75% 수취 (개발자 실수취분은 이보다 낮음)
- 상위 1,000명 개발자 연평균 11억원 수익
- 로블록스 스튜디오 사용자 300만명 이상

### 실행 방법 (HOWTO)
1. 로블록스 스튜디오로 게임 제작
2. 루아우(Luau) 언어 및 엔진 API 학습
3. 배포 버튼을 통한 간편 배포 시스템 활용
4. 3D 모델링 AI 및 AI 에이전트를 개발 과정에 활용

### 핵심 요소 (CORE)
- 로블록스 내 게임 개발 및 수익화 가능
- 루아우(Luau) 언어 사용
- 플랫폼 수수료 및 환전 구조 존재

## 리스크/약점

- **플랫폼 종속 리스크**: 수익 구조 전체가 로블록스 정책에 종속 — 수수료·정책이 바뀌면 수익 모델이 통째로 흔들림
- **수익 쏠림 구조**: 상위 1,000명만 연평균 11억이라는 것은 역으로 그 아래 절대다수는 수익성이 불투명하다는 의미 (long-tail 리스크)
- **높은 플랫폼 수수료**: 로블록스 측이 매출의 약 75%를 가져가는 구조 — 개발자 실수취 마진이 낮음
- **[미검증] 세금 신고 절차**: 로블록스 플랫폼 수익에 대한 국내 구체적 세금 신고 절차가 원본 자료에 언급되지 않음 — 확정 전 별도 확인 필요
