# [003] 학습 자동화 시스템 브랜드

- **카테고리**: 콘텐츠+디지털 상품 결합형 (개인 브랜드)
- **상태**: 아이디어 — 최종 추천 1순위, **지금 바로 착수 가능**
- **등록일**: 2026-09
- **출처**: 사용자 제공 (50개 아이템 카탈로그 중 ★최종 추천)

## 한 줄 요약

본인이 수능 준비 과정에서 직접 만든 성적분석·학습계획 체계를, 검증로그(콘텐츠) + 동적 템플릿(노션+Make) + 프롬프트팩(디지털 상품) 3종으로 쪼개 상품화하는 개인 브랜드.

## 핵심 강점 (Fusion 재료)

- **S1. 제로 초기자본 + 즉시 착수**: 이미 보유한 자료(본인 성적분석·학습계획 체계)를 그대로 재료로 쓰므로 신규 제작·리서치 없이 지금 바로 시작 가능
- **S2. 1차 데이터 기반 경쟁우위**: 본인의 실제 학습 실험·수치를 그대로 공개하는 검증로그 콘텐츠라 경쟁자가 복제 불가능
- **S3. 콘텐츠→상품 이중 구조**: 콘텐츠(검증로그)로 신뢰·트래픽 확보 → 템플릿/프롬프트팩으로 직접 수익화. 두 축이 서로의 마케팅 비용을 대체함
- **S4. 동적 템플릿의 모방 난이도**: 정적 문서가 아니라 실제 작동하는 노션+Make 자동화 시나리오라 경쟁이 적음
- **S5. 실적 기반 신뢰자산**: 본인의 실제 수능 준비 성과가 있어 외주형 대비 신뢰장벽을 빠르게 넘을 수 있음

## 상세 설명

3종 상품 구조:
1. **검증로그 콘텐츠**: 본인의 학습 실험·성적 변화 수치를 그대로 공개 (블로그/SNS)
2. **동적 템플릿**: 성적분석·학습계획을 노션+Make로 자동화한 워크플로우 세트로 판매
3. **프롬프트팩**: 학습계획 수립·성적분석에 쓰는 프롬프트+사용가이드 묶음 판매

이 구조 자체가 이미 카탈로그의 다른 두 A등급 아이템(검증로그 콘텐츠 미디어, 노션+Make 동적 템플릿)을 "학습" 버티컬에 적용해 결합한 사례 — 즉 003은 004·006의 조합형 선행 사례다.

- 초기자본: 0원
- 자동화율: 80%
- 시점: 지금 바로 가능

## 리스크/약점

- 타겟 시장이 좁을 수 있음(수능생/학부모 한정) — 확장성은 별도 검증 필요
- 검증로그 콘텐츠의 지속 생산 부담 — 매주 실험 결과를 공개해야 하므로 소재 고갈 리스크 존재
- 본인에게 통한 학습법이 타인에게도 통한다는 보장 없음 — 사회적 증명(타인 적용 사례)이 추가로 필요
- 미성년 신분으로 상거래·정산 시 법정대리인 필요 여부 [미검증]
