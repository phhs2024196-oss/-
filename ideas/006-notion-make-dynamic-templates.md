# [006] 노션+Make 동적 워크플로우 템플릿 판매

- **카테고리**: 디지털 상품 판매형
- **상태**: 아이디어
- **등록일**: 2026-09
- **출처**: 사용자 제공 (50개 아이템 카탈로그, 등급 A)

## 한 줄 요약

실제로 작동하는 자동화 시나리오(Make/n8n)와 노션 DB 세트를 묶어서 판매. 정적 템플릿이 아니라 "작동하는 시스템"을 판다.

## 핵심 강점 (Fusion 재료)

- **S1. 모방 난이도가 높은 상품**: 정적 문서와 달리 실제 작동하는 자동화 로직이라 복제·역설계가 어려움 — 경쟁이 적음
- **S2. 검증된 자동화 노하우의 재판매**: 자신이 이미 구축해본 업무자동화 패턴을 그대로 상품화 가능 — 제작 경험 자체가 재고
- **S3. 체감가치 대비 낮은 한계비용**: 구매자는 "바로 작동하는 시스템"이라 체감가치가 크고, 판매자는 추가 제작비용이 들지 않음

## 상세 설명

- 초기자본: 0원
- 자동화율: 85%
- 버티컬 AI 업무자동화 스튜디오(001)를 실행하는 과정에서 만든 자동화 로직이 그대로 이 상품의 재료가 됨 — 001 실행의 부산물로 만들면 효율적

## 리스크/약점

- 제작 난이도(자동화 툴 지식 필요) — 진입장벽이 004(검증로그)보다 높음
- 플랫폼(Make/노션) API 변경 시 유지보수 필요
- 001과 제작 노하우가 상당 부분 겹침 — 별도 기획보다 001 실행 중 부산물로 접근하는 편이 유리
