# [008] 웹사이트 플리핑 (Flippa)

- **카테고리**: 디지털 자산 거래형
- **상태**: 아이디어 — **조건부** (매입자본 형성 후 재검토)
- **등록일**: 2026-09
- **출처**: 사용자 제공 (50개 아이템 카탈로그, 등급 A(조건부))

## 한 줄 요약

AI로 빠르게 사이트를 구축하거나 저평가된 사이트를 매입 → AI로 개선 → Flippa 등에서 재매각. 마이크로SaaS의 장기 운영형과 달리 단기 현금화 사이클.

## 핵심 강점 (Fusion 재료)

- **S1. 시간당 수익 실증**: 시간당 71~146유로 수준의 실측 사례 존재
- **S2. 단기 사이클 현금화**: 매입→개선→매각의 상대적으로 짧은 주기로 자본을 회전시킴 (장기 구독형 자산 축적과 대조되는 전략)
- **S3. AI로 개선 작업 가속**: 콘텐츠 보강·SEO·UI 개선을 AI 도구로 빠르게 수행해 매각가를 끌어올릴 수 있음

## 상세 설명

- 초기자본: 매입자본 필요 (조건부 — 자본 형성 전엔 실행 불가)
- 자동화율: 70%
- 실행 시점: 다른 아이디어(001, 003 등)로 초기 자본을 형성한 이후 재검토 대상

## 리스크/약점

- 매입 자본이 전제조건 — 현재(초기자본 0원 단계)엔 실행 불가능
- 사이트 가치평가·실사 역량이 별도로 필요
- 미성년 신분으로 거래대금 정산 시 법정대리인 이슈 가능성 [미검증]
