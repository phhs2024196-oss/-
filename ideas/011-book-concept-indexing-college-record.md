# [011] 개념 인덱싱 활용 생기부 도서 추천 및 진로 연계 AI 솔루션

- **카테고리**: 도서관/서점 API 기반 개념 인덱싱과 RAG 결합 생기부 독서 가이드
- **태그**: 기타
- **상태**: 아이디어
- **등록일**: 2026-09
- **출처**: 사용자 제공 — "AI사업분석" 태그형 데이터

## 한 줄 요약

알라딘/교보문고 등 오픈 API로 목차·서평만 수집해 "개념 인덱스"를 만들고, 학생의 희망전공·탐구보고서와 매칭해 생기부용 독서를 추천하는 서비스.

## 핵심 강점 (Fusion 재료)

- **S1. 합법적 저작권 회피 구조**: 도서 원문을 직접 학습하지 않고 목차·서평 등 개념/구조만 인덱싱해 RAG를 구축 — 저작권 침해 리스크 없이 콘텐츠 기반 서비스를 만드는 구조 (원문 복제가 아닌 "구조화"로 법적 리스크 회피)
- **S2. 명확한 니즈 적중**: 완독 부담이 큰 학생층(생기부용 독서)의 실제 페인포인트를 정조준
- **S3. 이중 수익화 구조**: 어필리에이트(도서 구매 연동) + 이용료를 동시에 확보 가능

## 상세 설명

- 핵심 요소: 저작권 침해 없는 오픈 API(목차/서평) 기반 도서 개념 인덱싱 DB 구축, 학생 희망전공·탐구보고서 분석 후 맞춤형 독서 가이드 생성
- 실행 방법(HOWTO): 알라딘/교보문고 오픈 API 연동 → 목차·서평 데이터 수집 → 개념 인덱스 DB화 → 학생 보고서 분석 결합 → 구매링크(Affiliate) 연동

## 리스크/약점

- 추천 시스템 고도화를 위한 초기 학술 개념 인덱스 DB 구축에 상당한 공수 필요
- 수시 제도 변화에 따른 수요 변동성 — 입시 정책 리스크
