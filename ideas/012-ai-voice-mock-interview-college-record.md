# [012] 생기부 PDF 분석 기반 AI 음성 모의면접 솔루션

- **카테고리**: 학생부 PDF 분석 및 대학별 면접관 성향 RAG 기반 STT/TTS 모의면접
- **태그**: 기타
- **상태**: 아이디어
- **등록일**: 2026-09
- **출처**: 사용자 제공 — "AI사업분석" 태그형 데이터

## 한 줄 요약

생기부 PDF와 대학별 기출·인재상 RAG를 결합해, 실시간 음성(STT/TTS)으로 꼬리질문까지 구현하는 고단가 B2C 모의면접 서비스.

## 핵심 강점 (Fusion 재료)

- **S1. 높은 B2C 지불의사(WTP)**: 고관여 입시 시장 특성상 다른 교육 아이템 대비 실제로 돈을 낼 의사가 확실히 검증되는 영역
- **S2. 1:1 실시간 인터랙션의 높은 몰입도**: 텍스트 기반 서비스와 달리 실시간 대면 음성 면접 형태라 체감 서비스 품질이 높음
- **S3. 초개인화 데이터 결합의 고단가 정당화**: 생기부라는 초개인화 데이터와 실시간 음성 AI를 결합하면, 범용 서비스보다 훨씬 높은 단가를 받을 수 있는 근거가 생김

## 상세 설명

- 핵심 요소: 생기부 PDF·보고서 분석 기반 고도화 면접 질문 추출, STT/TTS 음성 인터페이스로 실시간 대면 모의면접 및 꼬리질문 구현
- 실행 방법(HOWTO): 생기부 PDF 텍스트 추출 파이프라인 구축 → 대학별 기출/인재상 RAG DB 연동 → STT/TTS 통합 실시간 음성 응답 구축 → 답변 논리성/꼬리질문 평가 리포트 제공

## 리스크/약점

- 고성능 STT/TTS+LLM 조합에서 실시간 대화 지연(latency) 제어가 기술적 난제
- 입시 시즌(9~11월) 집중으로 인한 계절성 매출 불균형 — 나머지 기간 수익 공백 대책 필요
