# [033] 인스타 카드뉴스 + 자동DM 제휴마케팅

- **수익모델(MODEL)**: 광고형, 커머스형(제휴마케팅)
- **타겟(TARGET)**: 인스타그램 사용자, 쇼핑/여행 상품 구매 잠재 고객
- **상태**: 아이디어
- **등록일**: 2026-09
- **출처**: 사용자 제공 (v2 태그형) — 유튜브 "머니로드 - 돈 길치 가이드"
- **근거 신뢰도**: 크리에이터 본인 실적 공개

## 한 줄 요약

인스타그램 카드뉴스(이미지) 게시물로 트래픽을 유도하고, 댓글에 자동 DM을 보내 제휴 링크 클릭을 유도해 수수료를 받는 구조. 영상 없이 이미지 1장으로 운영.

## 핵심 강점 (Fusion 재료 — 일반)

- **S1. 영상 편집 불필요**: 이미지 카드뉴스 방식이라 쇼츠(029·031·032)보다 제작 난이도가 더 낮음
- **S2. 플랫폼 알고리즘 우대**: 인스타그램이 공식적으로 카드뉴스 형태 노출을 우대
- **S3. 높은 수수료 구조**: 3~38%의 상대적으로 높은 제휴 수수료율
- **S4. 리드→구매 퍼널 자동화**: 댓글 자동 DM 발송으로 트래픽을 구매 링크까지 자동으로 이어붙임 — 029~032가 "링크를 댓글에 다는" 수동적 방식인 것과 달리 능동적 전환 유도 단계가 자동화되어 있음

## 상세 설명

- 핵심 요소(CORE): 인스타그램 카드뉴스 이미지 게시물 트래픽 유도, 제휴 마케팅 링크 클릭 수수료화, 댓글 자동 DM 발송 자동화
- 수치 근거(NUM): 초기자본 0원, 하루 7개 제작 시 30분 이내, 월 100~1,000만원(개인 실적 기준)
- 요구 기술(SKILL): 낮음 — 개발된 AI 카드뉴스 제작 툴, 자동 DM 세팅 툴(텀플로우)
- 실행 방법(HOWTO): 주제 선정 → 제휴 링크(쿠팡파트너스, 트립닷컴 등) 생성 → AI 툴로 카드뉴스 이미지 생성 → 인스타그램 게시 → 텀플로우로 댓글 자동 DM 세팅
