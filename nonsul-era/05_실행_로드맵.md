**결정 게이트 B (1/10)**: 측정값으로 일정 재작성.
3월 말 파일럿 목표(숭실 252 + 동국 232 + 세종 232 = 716문항)의 실제 신규 작업량 계산:
- 유유상종(70/교)은 보유 300문항(100/교)으로 충당 → 신규 0 (범위 재제작 제외)
- 기생기사·다다익선(48/교) = 기출 해설 → P3로 3개교 144문항
- 백전불태(실전 1회 문항 수 × 20회: 숭실 4×20 = 80, 동국·세종 3×20 = 60) + 난공불락 30 → 숭실 110 + 동국 90 + 세종 90 = 신규 **290문항 ≈ 29세트**
- 만류기종은 재수록 → 신규 0

- 같은 기간 목표인 **나머지 12개교 기출 DB**(학교당 P3 세션 1개 + 검수) → 약 12세션

→ 하루 1세트(평일) + 주 2~3회 기출 세션이면 약 7~8주(1/11~3/7)에 끝난다(29세트 + 기출 3개교 + 12개교). 2028 범위 축소로 208문항 재제작이 붙으면 약 4주가 늘어 3월 말이 빠듯해진다 → 측정 결과 하루 1세트가 안 되거나 재제작이 필요하면 백전불태를 2시즌만 먼저 내는 식으로 범위를 줄인다.

```
제목: 논술고사 기출문항 및 선행학습영향평가 보고서 활용 범위 문의

안녕하세요. 수험생 대상 수리논술 학습 교재를 준비하고 있는 「논술의 시대」입니다.
귀 대학이 공개한 ○○학년도 논술고사 기출문항·모의논술·선행학습영향평가 보고서를 아래 방식으로 활용해도 되는지 문의드립니다.

1. 문항 원문을 출처(대학명·학년도·문항 번호)를 밝혀 교재에 수록하고, 자체 작성한 해설·채점 예시를 함께 싣는 것
2. 원문은 싣지 않고 출처만 밝힌 뒤 자체 해설과 변형 문항을 싣는 것
3. 유료 판매 교재(PDF·종이책)에 위 1 또는 2를 사용하는 것

허용 범위와 필요한 절차(사전 승인, 표기 방식 등)를 알려 주시면 그대로 따르겠습니다. 감사합니다.
```

## 부록 B. 교육지원청 서면 질의 (국민신문고)

```
제목: 수리논술 교재 판매 및 AI 답안 첨삭 서비스의 학원법상 등록 대상 여부 질의

1. 수리논술 문제집을 PDF·종이책으로 온라인 판매만 하는 경우(강의·질의응답 없음) 학원 또는 원격교습 등록 대상인지
2. 수험생이 손글씨 답안 사진을 올리면 AI가 채점표 기준으로 점수·피드백을 자동 제공하는 유료 서비스(시즌 단위 이용권, 실시간 강의 없음)가 「학원의 설립·운영 및 과외교습에 관한 법률」상 원격 교습에 해당하는지, 해당한다면 필요한 등록 요건
3. 상호에 '학원'을 쓰지 않는 경우 위 1·2와 관련해 유의할 점

서비스 개시 전에 법령을 지키기 위해 문의드립니다.
```
