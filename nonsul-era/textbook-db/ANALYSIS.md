작성: 논술의 시대 / 용도: 자체 교재 기획·집필 시 참고 (내부용)
근거 자료: 교재별·쪽구간별 요약 노트(notes/), 문항 DB 집계(stats.md, all.jsonl의 role·cited_source·subject·concepts·skills·level 필드만 집계)

## 0. 사용 원칙 (먼저 읽을 것)

- 이 문서는 타사 교재의 구조, 흐름, 아이디어만 분석한다. 타사 문항, 해설 문장, 그림, 표현을 그대로 가져와 우리 교재에 싣지 않는다.
- 대학 기출 자체는 각 대학이 공개한 자료이므로 출처를 밝히고 쓸 수 있으나, 타사가 고른 문항 조합, 소문항 재구성, 변형 문항은 따라 하지 않는다. 기출은 우리가 원자료(대학 공개본)에서 직접 고른다.
- 본문의 개념 요약은 모두 자기 말로 줄인 것이다. 집필 때는 이 요약을 다시 보지 말고 교과서와 대학 공개 자료에서 새로 쓴다.
- 난이도(하·중·상·최상)는 DB 입력 담당이 문항을 보고 매긴 판단값이다. 타사 책에는 난이도 표시가 거의 없으므로 참고치로만 쓴다.
- 문항 수는 stats.md 기준이다. 해설 항목은 문항과 별도로 센다. 쪽수는 PDF 쪽 기준(표지와 백지 포함)이라 인쇄 쪽수와 몇 쪽 다를 수 있다.

## 2. 교재별 양식 분석

### 2.1 여상진 정규반 교재군 (YSJ-MATH, DIF, INT, GEO / 정규반 교재)

공통 골격은 네 권이 거의 같다.

**장 구성 순서**
1. 장 구분 쪽: 장 번호와 제목, 그 아래 "개념정리 / 예제 / 실전문제" 목차만 있는 한 쪽.
2. 개요 박스: 교과서 연계 단원, 핵심 내용, 논술 기출 및 예상 유형(항목 나열), 저자 총평 문단.
3. 개념정리: 번호 소제목(1. 2. 3.), 이름 붙은 정리는 테두리 박스, 필요하면 "참고" 박스와 증명.
4. 예제 NN-k: 쪽마다 한 문항, 아래는 풀이 공간으로 비워 둠.
5. NN 실전문제: "논제 N."으로 부르고 쪽마다 한 논제.
6. 책 맨 뒤 해설: 장 순서 그대로, 예제와 논제 풀이만 있고 문항은 재수록하지 않음.

**박스·코너 이름과 역할**
- 개요 박스: 이 장에서 논술이 무엇을 묻는지 미리 알려 주는 지도. "예상 유형" 목록이 학습 목표 역할을 한다.
- STEP 라벨: 풀이 절차를 단계로 쪼갠 표시(예: 다항함수 결정은 차수 → 최고차항 계수 → 나머지 계수). 방법을 외우게 하는 장치다.
- 참고 박스: 교과 밖 공식이나 감점 위험을 알리는 곳. 교과서에 없는 공식을 쓰면 감점될 수 있다는 경고가 반복된다.
- 해설편의 (참고)와 (다른 풀이): 대안 풀이와 함정을 알려 주는 코너. 증명이 끝나면 ■를 쓴다.

**개념 → 예제 → 실전 흐름**
- 개념은 짧고 결론 위주다. 대신 증명 가능성이 있는 정리(사인법칙, 코사인법칙, 접선 공식, 평균값 정리 등)는 증명 방법을 함께 적는다.
- 예제는 출처 표기가 없거나 대학명만 손글씨로 적혀 있다. 실전문제는 제목줄에 "[대학 연도]"를 붙인다.
- 따라서 예제는 "개념 적용 훈련", 실전은 "실제 기출 서술 훈련"으로 역할이 갈린다.

**출처 표기**: 문항 제목 옆 대괄호(`[대학 연도]`, 모의는 `[대학 연도 모의]`, 계열 표기는 의예 정도). 해설편에는 출처가 없다.

**해설 방식**
- 인쇄 해설이며 소문항 (1)(2)(3) 순으로 푼다. 왜 이 방법인지, 어디서 점수를 잃는지를 서술하는 비중이 높다.
- 저자가 강조하는 점은 거의 같은 방향이다. 직관과 그림만으로 끝내면 엄밀성 감점, "…"로 생략하지 말고 귀납법·귀류법으로 쓸 것, 조건을 모두 썼는지 확인할 것.
- 같은 문제에 풀이 두 가지(판별식/음함수 미분, 기하/미분 등)를 병기하는 경우가 많다.

**난이도 배치**: 표시 없음. 장 안에서 예제가 먼저, 실전 논제가 뒤라는 순서가 난이도 순서의 전부다. DB 판단으로는 중과 상이 대부분이다.

**권별 차이점**
- 수학 상·하(YSJ-MATH): 10개 장, 다항함수 결정, 무리수·복소수, 이차함수, 영역, 평면기하, 집합, 절대부등식, 일대일대응, 삼각함수, 사인·코사인법칙. 5장에 "계산량 줄이기"라는 손글씨 부제가 붙어 있다.
- 미분(YSJ-DIF): 미분가능성, 초월함수 미분, 여러 가지 미분법, 롤·평균값 정리, 그래프, 접선, 속도·가속도, 매개변수 8개 장. 장마다 저자 총평이 길다.
- 적분(YSJ-INT): 급수의 수렴, 구분구적법, 적분과 미분의 관계, 치환·부분적분, 대칭성, 넓이, 길이·부피 7개 장.
- 기하(YSJ-GEO): 이차곡선 성질, 접선, 평면벡터, 삼수선·이면각, 정사영 5개 장. 해설에서 풀이 방법이 둘이면 [i] [ii]로 구분한다.

### 2.2 여상진 정규반 23회 (YSJ-R23 / 정규반 회차 교재)

- 구성: 표지, 개념(공간의 점·직선·평면 기본 성질), 실전연습문제 논제 1~5.
- 특징: 개념 쪽에서 유클리드 공리, 평행선 공리와 비유클리드 기하까지 맛보기로 소개하되, 증명은 가장 중요한 것만 싣는다고 밝힌다.
- 논제마다 문제 쪽 바로 뒤에 "논제N 해설"이 붙는 구조로, 한 문제 한 쪽씩 독립이다.
- 배점과 난이도는 없다. 출처는 대괄호 표기.

### 2.3 여상진 모의논술 (YSJ-MK19, 21, 22, 23 / 실전 모의)

- 시험지 형태로 제목은 "정규반 모의논술시험 N회(이공계)". 논제별 배점을 [5~30점]으로 다르게 준다.
- 조건은 박스에 넣고, 소괄호 "(도움말: …)"로 필요한 정리나 풀이 방향을 일부 제공한다. 출처는 표기하지 않는다.
- 회차별 단원 편중이 뚜렷하다. 19회는 확률과 미적분 혼합, 21회는 이차곡선, 22회는 평면벡터, 23회는 공간도형. 즉 "단원 모의"에 가깝다.
- 해설은 별도 파일(2~4쪽)로 논제별 서술형 모범풀이이며, (다른 풀이)와 (참고) 코너를 쓴다. 23회는 해설이 없다.
- 문항 수 5~6개, 문항당 소문항이 이어지는 연쇄형. 배점이 큰 마지막 논제가 가장 어렵다.

### 2.4 김기원 겨울특강 7회차 (KKW-W7 / 특강 시험지)

- 머리글 "수리논술의 시작 제 7 회", 제목 "오늘의 논제 N", 우측에 출처를 문항 번호까지 적는다(학년도, 대학, 오전·오후, 문항 번호).
- 제시문은 박스, 소문항은 (1-1), (1-2)처럼 논제번호-소번호. 풀이 공간 공백, 배점·답·해설 없음.
- 확인된 것은 2문항뿐이라 일반화하기는 어렵다. 다만 "출처에 시험 회차·문항 번호까지 적는" 방식은 참고할 만하다.

### 2.5 ANALOG 수학Ⅱ·미적분 (ANA-C2 / 워크북)

**장 구성**: Theme 01 극한 → 02 급수 → 03 연속 → 04·05 미분 → 06·07 적분. 각 Theme는 표지(과제 목록과 해설 목록) → Assignment 3~6개 → Analysis's Solution 5개.

**Assignment 한 편의 구조**
1. 문제: 제목 박스에 출처(연도·대학·계열), 제시문 박스, 소문항 번호는 하늘색 배지(1-1, 1-2).
2. 답지: 대학 공식 해설을 책 안에 인쇄.
3. 코멘트: 저자가 학생에게 말하듯 쓴 짧은 학습 조언(유형 이름, 출제 의도, 주의점).
- 쪽 사이에 MEMO 빈 쪽을 끼워 필기 공간을 준다.

**Analysis's Solution**: 문제 원문 없이 손글씨 풀이만. 소주제 이름(예: 합성함수의 연속, 대칭성 적분)을 목차에 붙여 "이 문제의 기술"을 먼저 알려 준다.

**흐름**: 개념 강의는 거의 없고 Assignment 안의 코멘트가 개념 역할을 한다. 학생이 먼저 풀고, 대학 답지와 저자 코멘트로 점검하고, 손글씨 풀이로 같은 유형을 다시 본다.

**출처 표기**: 제목 박스에만 표기(문항 옆 별도 표기 없음). 배점과 난이도 표시는 없다.

**해설**: 답지는 인쇄체(대학 방식), 해설은 손글씨(조교 풀이), 코멘트는 저자 목소리로 세 층이다. 오탈자 의심 지점이 몇 곳 있다(DB 입력 중 성균관대 문항의 계산값 불일치 등).

### 2.6 ANALOG 기하·확률과 통계 (ANA-GEO, ANA-PS / 개념+기출 교재)

**장 구성**: 머리말 → 이 책의 활용법 → 목차 → Theme (기하는 이차곡선 / 평면벡터 / 공간도형과 공간좌표, 확통은 경우의 수 / 확률 / 이항정리 / 통계).

**Theme 한 편의 순서**
1. Preview(나침반): 이 Theme에서 무엇을 배우는지 안내.
2. 최신 Trend: 최근 출제 경향(예: 이차곡선은 정의와 접선 공식을 정직하게 쓰는 계산 위주, 이항정리는 심화 공식 출제가 줄고 정의 활용형이 늘어남).
3. 개념: 강의체로 서술. 제목 박스(기하는 보라색, 확통은 파란색)에 정의·공식, Proof 박스에 직접 증명 연습, HINT·Skill·Topic 띠.
4. ex: 개념 중간에 끼운 짧은 확인 문항. 출처에 수능·모평·학평 문항이나 "자체 제작"을 적고, 바로 아래 SOL 박스에 짧은 풀이를 준다.
5. practice: 독자가 직접 풀어 볼 예제(해설 수록).
6. Example NN: 기출 한 편. 4단 구성이 핵심이다.
 - 1 문제: 출처를 제목 박스에 병기, 소문항은 N-M 라벨.
 - 2 Univ's Solution: 대학 공식 답지.
 - 3 Analysis's Algorithm: 저자의 사고 과정을 구어체로 풀어쓴 해설.
 - 4 Analysis's Tip: Main Tip(그 쪽 상단 주제와 직결), Sub Tip(기타 요령).
7. 대학 답지가 없는 문항은 손글씨 해설로 대체하고, 손글씨 해설은 별책(해설편)에 수록.

**특징**
- 박스와 코너 이름이 영어로 일관되고 이름이 곧 역할이다(Main Tip, Sub Tip, Skill, Topic, ex, practice).
- 사고 과정 해설(Algorithm)이 대학 해설과 분리되어 있다. "답이 어떻게 나오는가"와 "왜 그렇게 생각했는가"를 나눠 쓴다.
- 학습 순서와 주당 분량(주 1 Theme)까지 제시한다.
- 난이도는 표시하지 않고 하나의 유형 라벨(예: "중복조합 - 차이의 관점 (1)", "확률 계산 (2)")로만 분류한다. 가끔 Basic, Hard를 단다.
- 수능 문항(객관식)을 개념 확인에 넣어 하 난이도 층을 만든 점이 정규반 교재와 가장 다르다.

### 2.7 ANALOG 손글씨 해설편 (ANA-GEOS, ANA-PSS / 해설집)

- 본책 문제 원문은 싣지 않고 해설만 있다. 머리띠에 "Analysis's Solution | 대학·연도·계열"을 쓰고 문항 번호는 원문자.
- 풀이는 줄글 + 수식을 한 줄씩 나열하고, 결론은 "∴" 또는 박스 처리. 그림도 손으로 그린다.
- 해설 쪽과 MEMO 빈 쪽이 번갈아 나온다. 약식 풀이도 있고(제시문 일부만 쓰는 대안 풀이) 완전 풀이는 대학 해설을 보라고 안내하기도 한다.
- 장점은 학생이 실제로 시험지에 써야 할 분량과 형식을 보여 준다는 것이고, 단점은 판독이 어렵고 오기가 섞이기 쉽다는 것이다.

### 2.8 서지현 기하편 (SJH-GEO / 개념+기출 교재)

- 구성: 1부 이차곡선 → 2부 평면벡터 → 3부 공간도형과 공간좌표. 각 부는 sub 단원(예: 접선, 광학적 성질, 최대·최소, 정사영)으로 나뉜다.
- 핵심 코너
- 논제 형태(I, II, III…): 문제를 "이런 형태로 묻는다"로 분류한 빨간 테두리 박스. 형태별 전략을 한두 줄로 준다.
- [논제의 결론]: 형태별로 최종적으로 구할 대상을 표시.
- 서술예시: 형태별 모범 서술 틀. 마지막은 "(후략)"으로 맺어 서술 구조만 보여 준다.
- 교과서 개념체크: 필요한 교과 개념만 모은 박스.
- 기출 문항: 큰 번호(01~38) + 쪽 머리의 출처, 아래에 점선 답안 작성란, 이어서 Solution 박스. 소문항별로 "Solution of (n)"을 붙이고 별해는 "Another Solution".
- 해설은 문항 바로 뒤에 이어진다. 경우 나누기는 i) ii) 표기에 종합 결론 문장을 꼭 쓰게 한다.
- 가장 큰 차별점은 "형태 → 전략 → 서술 틀"의 3단 구조다. 서술(답안 작성) 훈련에 가장 직접적이다.

### 2.9 우주설 엑셀시어 연세대편 (WJS-YS / 학교별 대비 교재)

- 구성: 01 부등식 증명과 샌드위치 정리 → 02 최대·최소 → 03 정수론적 사고 → 04 고난이도 기하 → 05 그 외 기타 문항 → 06 여러 가지 증명 논제 → 정답 및 해설.
- 코너: 전통적 출제 소재, 부등식 세우기, 적용 연습(타 대학 기출), 여러 가지 부등식 증명하기 [1~4단계], 연세대 6개년 기출 분석, 타학교 관련 기출 분석.
- 쪽당 한 문항, 번호 옆 둥근 상자에 출처(예: 연도 학교 기출/모의). 풀이 공간 공백.
- 해설: "정답 및 해설"에 (대학발표 예시답안) 표기를 달고, 문항별 [별해]를 병기한다. 제시문을 번호로 인용하며 "~에 의해"로 근거를 밝히고 마지막 줄에 결론을 한 문장으로 쓰는 답안 형식을 모범으로 삼는다.
- 학교별 소재 분석이라는 점이 다르다. 연세대에 맞춰 정수론, 함수방정식(한 점에서 연속이면 전체 연속)을 비중 있게 다룬다.
- 단계별 연습([1단계]~[4단계])은 난이도를 의도적으로 계단화한 드문 사례다.

### 2.10 셈이의 문제해결기법 (SEMI / 문제해결 기법서)

- 구성: 1 언어와 논리 → 2 관찰과 실험 → 3 변형과 비약 → 4 퇴고 기법 → 5 종합문제 → 풀이 및 해설.
- 절 안에서 설명 문단 → 예제 → 풀이/증명/별해 → 연습문제 순서로 반복한다. 연습문제 해설은 책 뒤에 문제와 함께 재수록한다.
- 코너 라벨: 관찰, 전략, 풀이, 증명, 별해/별증, 단계, 주(보충). 풀이 끝은 ◇, 증명 끝은 □.
- 가장 큰 특징은 문장 중간에 붙이는 회색 기법 태그다(귀류법, 불변량, 대칭성, 서술범위 좁히기 등). 풀이를 읽으면서 어느 지점에서 어떤 기법이 쓰였는지 바로 보인다.
- 소절 제목을 명령형(~하자)으로 쓴다.
- 출처는 문두 괄호로 대회 이름과 연도(IMO, Putnam, KMO 등)를 적고, 난이도 표시는 없다. 연습문제 일부는 답이 없다.
- 4장 퇴고 기법은 기술이 아니라 태도(선입견 버리기, 검산, 출제자 의도 읽기, 포기하지 않기)를 다룬다.

## 3. 개념 체계

### 3.1 수학(상·하), 수학Ⅰ·Ⅱ 영역

여러 교재가 공통으로 강조하는 것
- **함수방정식**: 특수값 대입 → 차수나 구조 판단 → 계수 비교 → 반드시 대입해 재확인. 여상진(정규반 교재)은 다항함수 결정 3단계로 정형화했고, 우주설(학교별 대비 교재)은 자연수 → 정수 → 유리수 → 연속성으로 실수까지 확장하는 증명 흐름을 반복한다. 셈이(문제해결 기법서)는 이를 "아이템 모으기"와 "연립해 소거"로 설명한다.
- **귀류법과 홀짝·나머지 분류**: 무리수, 주기 없음, 개수 불가능 등에서 반복 등장한다. 여상진(정규반 교재)은 주기함수 증명에서 "…"로 얼버무리지 말고 귀납법을 쓰라고 한다. 셈이(문제해결 기법서)는 귀류법을 가장 많이 쓰는 논증으로 소개한다.
- **절대부등식**: 삼각부등식, 산술기하, 코시-슈바르츠. 등호 조건과 "최솟값임을 보이는 절차"를 구분하는 것이 공통 강조점(산술기하로 구한 값이 최솟값임은 등호 성립 가능성까지 확인해야 함).
- **일대일대응, 집합, 격자점**: 증명 시 단사와 전사를 모두 서술. 유한집합에서는 한쪽만 증명해도 된다는 예외를 활용한다.
- **삼각함수와 평면기하**: 변수 통일, 좌표 설정, 법칙 증명(사인법칙은 예각·직각·둔각 경우 나눔, 코사인법칙은 좌표로 증명).

교재마다 다른 접근
- 여상진(정규반 교재)은 "교과서에 있는 방식으로 쓰라"는 방침이 뚜렷하다. 신발끈 공식 같은 비교과 공식은 피하게 한다.
- 우주설(학교별 대비 교재)은 대학 예시답안에 맞춘 서술을 강조한다. 증감표를 반드시 쓰라고 하는 것이 대표적이다.
- 셈이(문제해결 기법서)는 교과 범위를 넘어 올림피아드 수준(비둘기집, 불변량, 최소원의 원리)을 가르친다. 대학 논술에서 바로 쓰이는 범위는 일부다.

### 3.2 미적분 영역

공통 강조 개념
- **샌드위치 정리(극한의 대소 관계)**: DB 집계에서 미적분 문항 중 가장 자주 나오는 개념이다. 극한 계산이 안 되면 부등식으로 조이라는 조언이 ANALOG(워크북)와 우주설(학교별 대비 교재), 여상진(정규반 교재) 모두에 있다. "3항 부등식을 세우는 것"이 어렵다는 진단도 같다.
- **평균값 정리·롤의 정리·사잇값 정리**: 존재성 증명 도구. 상황을 함수로 모델링 → 연속·미분가능 확인 → 정리 적용의 3단이 공통 서술이다.
- **미분가능성**: 정의(극한)로 판정. 구간별 함수, 함수방정식으로 한 점의 성질을 전체로 확장하는 패턴이 반복된다.
- **구분구적법(정적분과 급수)**: 급수가 정적분으로 바뀌는 신호(lim, Σ, k/n 꼴, 1/n 곱)를 짚는다. 오차를 부등식으로 논증하는 쪽은 여상진(정규반 교재)이 특히 깊다.
- **적분 기술**: 치환, 부분적분, 부분분수, 점화식, 대칭성(x → a−x 치환 후 더하기), 적분으로 정의된 함수의 양변 미분.
- **넓이·길이·부피**: 공식 암기보다 정적분 식을 쓰는 단계까지 적을 것(공식만 쓰면 감점 가능).

교재마다 다른 접근
- 여상진(정규반 교재): 단원마다 "증명을 요구받는 지점"을 짚는다(합성함수 미분 증명, 곡선 길이 공식 유도 등). 해설에서 같은 값을 다른 방법으로 구해 비교한다.
- ANALOG(워크북): 학교별 기출을 과제로 주고 코멘트로 "이 문제의 유형 이름"을 가르친다. Theme 구성이 개념 순서이지만 기술 중심으로 읽힌다.
- 우주설(학교별 대비 교재): 소재를 연세대 출제 취향(부등식 증명, 정수론, 함수방정식)으로 재편성한다.
- 김기원(특강 시험지): 구간을 쪼개 평균값 정리 적용, 도함수 근의 개수로 원함수 근의 개수 제한 같은 논증 패턴을 기출로 보여 준다.

### 3.3 확률과 통계 영역 (주로 ANALOG 확통)

- **경우의 수**: "효율성과 정확성(중복 X, 누락 X)"이 기본 태도. 합·곱의 법칙, 여사건, 대칭성을 도구로 하고, 분할 먼저 → 분배 순서를 강조한다. 원순열은 하나 고정 후 직선순열을 권장한다.
- **중복조합**: DB에서 확통 문항 중 가장 많이 나온 개념. 모든 상황을 "x₁+…+xₙ=r의 음이 아닌 정수 해"로 번역하는 것이 핵심 관점이고, 자연수 조건·짝홀 조건은 치환으로, 인접 차이 조건은 차이를 미지수로 둔다.
- **확률**: 조건부확률은 표본공간의 축소, 서술할 때는 사건에 이름을 붙이고 공식 대입으로 쓰라고 한다(연습장 풀이와 답안 풀이를 구분해서 보여 준다). 독립은 국어적 해석이 아니라 곱셈 성립 여부로만 판정한다.
- **점화 관계**: n번째에서 n+1번째로 갈 때 무엇이 바뀌는가를 본다. 첫 결과로 경우를 나눈다.
- **이항정리**: 정의와 역연산(합 모양에서 (a+b)ⁿ을 떠올리기), 미분·적분으로 계수 합 공식 만들기, 큰 수의 나머지는 10±1 꼴로 전개. 수능 수준 공식과 논술 심화 공식을 구분해서 가르친다.
- **통계**: 확률변수를 무엇으로 정의할지가 출발점. 이항분포의 평균·분산 유도, 정규근사 조건, 표본평균의 분포, 신뢰구간 길이. 논술 서술에서는 확률분포표를 반드시 쓰라고 한다.
- 셈이(문제해결 기법서)는 확률 단원 자체가 아니라 "두 가지 방법으로 세기", "비둘기집", "재귀"를 조합론 기법으로 제공해 ANALOG와 겹치는 도구를 다른 언어로 설명한다.
- 여상진 모의논술 19회(실전 모의)는 확률을 미적분(등비급수, 이항전개와 극값)과 섞어 출제했다. 즉 확통 단독보다 융합이 논술에서 현실적이다.

### 3.4 기하 영역

- **이차곡선**: 거의 모든 교재가 "정의에서 출발한다"를 최우선으로 둔다. 거리 합 일정 = 타원, 거리 차 일정 = 쌍곡선, 초점과 준선까지 같은 거리 = 포물선. 추론형 문항(조건에서 곡선을 알아내기)의 단서 목록도 비슷하다.
- **접선**: 접점·기울기·곡선 밖 한 점의 3가지 재료에 따라 방법을 고른다. 판별식 D=0 또는 음함수 미분으로 공식을 직접 유도해 볼 것을 권한다. 기울기 공식은 y축에 평행한 접선을 놓친다는 주의도 함께 나온다.
- **평면벡터**: 위치벡터와 내분점, 일차결합의 계수 비교, 내적의 세 관점(정의·성분·정사영), 중점 벡터로 내적을 거리 제곱의 차로 바꾸기, 벡터 조건을 도형(원, 타원, 선분)으로 번역하기.
- **공간도형**: 삼수선의 정리, 이면각, 정사영 넓이(S′=S·cosθ), 정사영 길이, 단면 그리기와 좌표 설정. DB에서 이면각과 정사영 넓이가 기하 개념 중 가장 많이 나온다.
- **공간좌표**: 거리, 내분·외분, 구의 방정식. 서지현(개념+기출 교재)은 각의 최대를 "함수화 후 미분"과 "외접원 + 사인법칙"의 두 방법으로 가르친다.

교재마다 다른 접근
- 여상진(정규반 교재): 개념 → 증명 가능성 → 기출 순. 해설에서 그림만 이용한 풀이는 엄밀성 감점이라고 반복 경고한다. 정다면체는 한 변을 2로 고정하는 등의 계산 요령도 준다.
- ANALOG(개념+기출 교재): 구어체 강의로 "왜?"와 "어떻게?"를 설명하고, 관점 선택(정의/성분/정사영)을 코멘트로 알려 준다. 공간도형은 평면 단면으로 줄여 푸는 방식을 강조한다. "경유점"(Skill 01) 같은 이름을 붙여 기술화한다.
- 서지현(개념+기출 교재): 논제 형태별 분류와 서술 틀. 광학적 성질(접선과 두 선분이 이루는 각이 같다)을 서술에서 어떻게 인용할지까지 보여 준다.
- 여상진 모의논술 21·22·23회(실전 모의): 기하를 회차 단위로 모아 단원 간 융합 대신 한 단원 심화로 출제한다.

형식: 기법 이름 / 언제 쓰나 / 핵심 아이디어. (SEMI = 셈이의 문제해결기법(문제해결 기법서))

### 4.1 SEMI의 기법 (장별)

**1장 언어와 논리**

| 기법 | 언제 쓰나 | 핵심 아이디어 |
|---|---|---|
| 그림·표 활용 | 집합, 그래프, 좌표, 배열이 있을 때 | 구조를 눈에 보이게 만들어 규칙, 경우, 모순을 찾는다. 그리는 방법 자체도 개선 대상이다 |
| 보조선 | 도형 문제에서 길이나 각이 막힐 때 | 닮음, 원주각, 이등변삼각형이 드러나도록 선을 긋는다 |
| 연립 | 구하는 값 외에도 모르는 값이 있을 때 | 모르는 값에도 변수를 두고 식을 여러 개 세운 뒤 소거한다. 함수방정식(f(−x) 소거)에도 쓴다 |
| 경우 나누기 | 한꺼번에 설명이 안 될 때, 논리 퍼즐 | 빠짐없이, 겹치지 않게 나눈다. 선입견을 피하고 조건문의 참·거짓 규칙을 정확히 쓴다 |
| 홀짝·나머지 분류 | 순환 구조, 제곱수, 합동식 | 홀짝과 3, 4, 6 등으로 나눈 나머지로 후보를 제거하거나 불가능성을 보인다 |
| 좋은 표기법 | 변수 설정이 식의 길이를 좌우할 때 | 약수 조건 등을 바로 반영하는 문자 설정으로 식을 줄인다 |
| 적절한 정의 | 연산이 낯설어 보일 때 | 익숙한 구조로 옮기는 대응을 정의해 낯선 연산을 곱셈 같은 꼴로 바꾼다 |
| 귀류법 | 결론이 부정형이거나 모든·어떤·적어도가 들어갈 때 | 결론을 부정해서 얻은 추가 가정으로 모순을 낸다 |
| 수학적 귀납법 | 자연수 전체에 대한 명제 | 일반화한 명제를 귀납하거나, 2ᵏ꼴 후 임의의 n으로 확장(역방향 귀납)한다 |
| 재귀(점화식) | 구조가 작은 경우로 환원될 때 | 반복되는 부분에 착안해 aₙ과 aₙ₋₁, aₙ₋₂의 관계식을 세운다 |
| 비둘기집 원리 | 개수 비교, 같은 부류의 존재 | 상자를 영리하게 정의한다. 대개 귀류법, 작은 문제와 함께 쓴다 |

**2장 관찰과 실험**

| 기법 | 언제 쓰나 | 핵심 아이디어 |
|---|---|---|
| 관찰과 추측 | 규칙이 안 보일 때 | 작은 n을 직접 계산해 표를 만들고 규칙을 추측한 뒤 귀납법이나 점화식으로 증명한다 |
| 반복성·주기성 | 큰 합, 지수, 주기함수 | 주기를 추측하고 합동식 등으로 확인한다. 주기함수이면 한 주기만 확인하면 된다 |
| 대칭성 | 게임, 함수방정식, 작도 | 대칭점이나 대칭 전략으로 조건을 변환한다 |
| 볼록성·오목성 | 부등식, 점 배치 | 그래프 해석과 젠센 부등식, 볼록 껍질을 잡고 귀류법 |
| 연속성과 흔들기 | 해의 존재, 동시 사건 해소 | 매개변수를 움직여 부호 변화를 만들고 사잇값 정리를 쓴다. 살짝 흔들어 겹침을 없앤다 |
| 유한성·무한성 | 소수의 무한성, 수열의 성질 | 유한이라고 가정하고 가장 큰 것으로 새 원소를 만들어 모순을 낸다 |
| 불변량 | 조작이 반복되는 게임·타일링 | 변하지 않는 값(합 mod n, 개수 차)을 잡아 불가능성을 보인다. 출제자가 불변량을 먼저 정하고 문제를 복잡하게 만든다는 설명이 인상적이다 |
| 색칠 활용 | 타일링, 게임, 세기 | 칸에 색이나 숫자를 대응시켜 불변량을 눈에 보이게 한다 |
| 고정점 | 움직이는 도형이 항상 지나는 점 | 방멱처럼 변하지 않는 곱이나 길이를 찾아 점을 확정한다 |
| 단조성 | 함수방정식, 가우스 기호 | 항상 증가(감소)한다는 사실 자체를 불변량으로 쓴다 |
| 아이템 수집·조립 | 목표가 막막할 때 | 특수값 대입이나 부분 결과를 아이템으로 모은 뒤 퍼즐처럼 맞춘다 |
| 극단적인 경우 | 부등식, 최대·최소, 존재 증명 | 극단 상태에서 답이나 등호 조건을 추측한다 |
| 이산 극값 원리(최소원) | 이산 대상에 최대·최소가 있을 때 | 최솟값을 갖는 대상을 잡아 그것에 대한 모순을 낸다 |
| 극단으로 몰고가기 | 선형·볼록 구조 | 일차식은 양 끝점만 보면 된다는 식으로 검토 대상을 줄인다 |

**3장 변형과 비약**

| 기법 | 언제 쓰나 | 핵심 아이디어 |
|---|---|---|
| 동치변형(알기 쉽게 옮기기) | 식이나 조건이 복잡할 때 | 치환 등으로 다루기 쉬운 꼴로 바꾸되 각 단계가 동치임을 확인한다 |
| 서술범위 좁히기 | 증명할 범위가 넓을 때 | 일반성을 잃지 않고(WLOG), 소인수 2만, x가 [0,1)인 경우만 보는 식으로 충분한 범위만 논한다 |
| 두 가지 관점에서 세기 | 개수 등식, 그래프 | 같은 양을 두 방식으로 세어 등식이나 부등식을 만든다 |
| 주인공 바꾸기 | 변수 선택이 계산을 좌우할 때 | 구하는 값 대신 다른 변수를 주인공으로 두고 판별식, 극단 등을 쓴다 |
| 다른 상식과 연관짓기 | 낯선 상황 | 이진법, 반각공식, 유클리드 호제법, 삼각치환 등 익숙한 모델에 대응시킨다 |
| 거꾸로 작업하기 | 결론에서 거슬러 오르기 쉬울 때 | 결론이 성립할 조건을 찾고 동치로 올라간다 |
| 목표 돌아가기 | 존재, 공점 증명 | 목표 성질을 가질 후보를 직접 잡아 보이는 방식으로 우회한다 |
| 더 작은 문제 먼저 | 큰 문제 | 작은 n이나 낮은 차원을 풀고 확장하거나 작은 식들을 조립한다 |
| 일반화 | 특수한 수 때문에 막혔을 때 | 상수를 변수로 올리면 귀납법이나 미분을 쓸 수 있고 귀납 가정이 강해진다 |
| 편한 충분조건 | 원래 조건이 증명하기 어려울 때 | 더 강하지만 확인하기 쉬운 조건을 대신 증명한다 |

**4장 퇴고 기법(태도)**: 선입견 없이 문제를 읽기, 문제 속 숫자와 표현에서 힌트 얻기, 출제자 의도 읽기(앞 소문항이 뒤 소문항의 보조), 결과 검산과 조건 누락 점검, 끈기.

핵심 일곱 가지 요약(저자 정리): 불변량, 아이템 모으기, 극단적 경우, 관점 바꾸기, 거꾸로 작업, 작은 문제 먼저, 일반화.

### 4.2 다른 교재의 Tip과 요령 (논술 직결형)

| 기법 | 언제 쓰나 | 핵심 아이디어 | 출처 |
|---|---|---|---|
| 정의로 풀기 | 이차곡선 문제 전반 | 보조선을 정의가 드러나게 긋는다(포물선은 초점 연결 + 준선에 수선, 타원·쌍곡선은 두 초점 연결) | ANALOG 기하(개념+기출 교재) |
| 미지수 선택(기울기 vs 접점) | 곡선 밖 한 점에서의 접선 | 구하는 값이 기울기·각이면 기울기를 미지수로, y축 평행 접선은 따로 확인 | ANALOG 기하(개념+기출 교재) |
| 경유점 | 한 번에 안 구해지는 벡터 | 중간 점을 하나 잡아 덧셈이나 뺄셈으로 쪼갠다 | ANALOG 기하(개념+기출 교재) |
| 중점 벡터 | 두 벡터의 내적이 복잡할 때 | 시점끼리, 종점끼리의 중점을 잡아 내적을 거리 제곱 − 상수로 바꾼다 | ANALOG 기하(개념+기출 교재) |
| 내적의 세 관점 | 내적이 나올 때 | 크기·각을 알면 정의, 좌표가 있으면 성분, 수선의 발이 보이면 정사영 | ANALOG 기하(개념+기출 교재) |
| 단면화·성분 분해 | 공간도형 | 평면 단면으로 줄이고, 선분을 교선에 평행한 성분과 수직인 성분으로 쪼개 정사영한다 | ANALOG 기하(개념+기출 교재), 여상진 기하(정규반 교재) |
| 삼수선으로 이면각 | 두 평면의 각 | 교선에 공통 수선의 발을 내려 삼수선 정리로 구하고, 안 되면 정사영 넓이비 | ANALOG 기하(개념+기출 교재) |
| 논제 형태 분류 | 서술형 답안 설계 | 문제를 형태로 분류하고 형태별 서술 틀에 맞춰 쓴다 | 서지현 기하편(개념+기출 교재) |
| 영역 위 최대·최소 분할 | 벡터 크기·내적의 최대 최소 | 영역의 특징점 Q를 잡아 AP=AQ+QP로 분할하고 방향을 맞춰 논증한다 | 서지현 기하편(개념+기출 교재) |
| 각 최대화 두 방법 | 공간좌표에서 각 최대 | 탄젠트를 함수로 보고 미분하거나, 외접원이 접할 때 반지름이 최소임을 이용 | 서지현 기하편(개념+기출 교재) |
| 사건 명명 | 조건부확률 서술 | 사건에 이름을 붙이고 공식 대입으로 쓴다 | ANALOG 확통(개념+기출 교재) |
| 차이의 관점 | 연속이 아닌 수 선택, 단조 함수 개수 | 인접한 두 수의 차를 미지수로 두어 중복조합으로 바꾼다 | ANALOG 확통(개념+기출 교재) |
| 미지수 setting | 개수 조건이 있는 중복조합 | 개수를 미지수로 두면 부등식 조건이 단순해진다 | ANALOG 확통(개념+기출 교재) |
| 항 비 비교 | 이항분포 등에서 최댓값 | 미분하지 않고 P(x+1)/P(x)와 1을 비교(나눗셈이 편함) | ANALOG 확통(개념+기출 교재) |
| 10±1 전개 | 큰 수의 거듭제곱 나머지 | 밑을 10 근처로 바꿔 이항전개하고 큰 지수 항은 소거 | ANALOG 확통(개념+기출 교재) |
| 계수 합 공식 | 이항계수 합 | 양변을 미분하거나 0~1 적분해 공식을 만든다 | ANALOG 확통(개념+기출 교재) |
| 샌드위치 3항 세우기 | 직접 계산이 안 되는 극한 | 증가·감소 정의, 도함수 부호, 급수 합, 정적분 대소, 평균값 정리의 5가지로 부등식을 세운다 | 우주설 연세대편(학교별 대비 교재) |
| 수열 최대·최소 두 방법 | 수열의 최댓값 | 연속화해 양옆 정수 비교, 또는 aₙ₊₁−aₙ의 부호 조사 | 우주설 연세대편(학교별 대비 교재) |
| 증감표 의무 | 최대·최소 답안 | 그래프만으로는 감점. 도함수 부호와 증감표를 함께 쓴다 | 우주설 연세대편(학교별 대비 교재) |
| 서로소 소거 | 정수 방정식 | 서로소 조건으로 인수를 소거해 후보를 줄인다(교재 속 별칭은 따로 있음) | 우주설 연세대편(학교별 대비 교재) |
| 정적분 씌우기 | 적분 부등식 | 피적분함수의 대소 관계를 먼저 보이고 양변에 정적분을 취한다 | ANALOG 워크북(워크북) |
| 한 점에서 전체로 | 함수방정식의 연속·미분가능 | 덧셈 꼴 관계로 한 점의 성질을 전체로 확장한다 | ANALOG 워크북(워크북), 우주설 연세대편(학교별 대비 교재) |
| 로그미분 | 곱, 몫, 지수에 x가 있는 함수의 미분 | 양변에 로그를 취해 미분한다. 결과에 y를 남기지 말고 x의 식으로 쓴다 | 여상진 미분(정규반 교재) |
| 대칭성 적분 | 부정적분이 안 되는 정적분 | x → a−x 치환 후 두 식을 더하거나 점대칭·선대칭 성질로 절반으로 줄인다 | 여상진 적분(정규반 교재) |
| 적분 관계식 4유형 | 적분 포함 관계식에서 함수 찾기 | 상수로 두기, 구간 길이 0 대입 + 미분, x를 밖으로 빼기, 치환 | 여상진 적분(정규반 교재) |
| 계산량 줄이기 | 평면기하 | 판별식 대신 중심과 직선의 거리, 절댓값 그래프는 꺾이는 점만 연결 | 여상진 수학 상·하(정규반 교재) |
| 좌표 설정 | 도형 문제 | 직각이 있거나 원점이 주어지면 좌표화(DB에서 기하 skills 중 가장 많음) | 여러 교재 공통 |
| 정사영 넓이 두 번 계산 | 이면각을 모를 때 | 정사영 넓이를 두 방법으로 계산해 방정식을 만든다 | 여상진 기하(정규반 교재) |

## 5. 우리 교재에 바로 쓸 시사점

### 5.0 원칙

- 구조와 아이디어는 참고하되 타사 문항, 문장, 해설 문구, 도식은 가져오지 않는다.
- 문항은 대학 공개 기출과 우리가 직접 만든 문항으로 채운다. 타사가 고른 조합과 소문항 구성은 따르지 않는다.
- 박스 이름도 타사와 같은 이름을 쓰지 않는다. 역할만 가져온다. (Main Tip, 논제 형태, 서술예시 같은 이름은 그대로 쓰지 말고 우리 이름을 새로 정한다.)

### 5.1 가져올 장점

**개념 쪽**
- 여상진(정규반 교재)의 "개요 박스": 교과 연계, 핵심, 논술 예상 유형을 한 박스에 넣어 학습 목표를 먼저 알려 준다. 절차탁마(개념·연습)의 장 시작에 적합하다.
- 여상진(정규반 교재)의 STEP 라벨: 절차형 풀이(함수 결정, 삼각함수 풀이)를 단계로 외우게 한다.
- ANALOG(개념+기출 교재)의 "최신 Trend"와 학습 순서 안내: 출제 경향을 한 쪽으로 정리해 학생의 우선순위를 정해 준다. 단, 경향 문장은 반드시 우리가 새로 조사해 쓴다.
- 증명 가능성이 있는 정리는 증명 방법을 한 줄이라도 달고, 직접 증명해 보라는 연습 칸을 둔다(여러 교재 공통 흐름).
- 서지현(개념+기출 교재)의 "논제 형태 → 전략 → 서술 틀": 서술 훈련에 직접 도움이 된다. 일타쌍피와 임기응변(신유형)에서 형태별 정리를 만들 때 구조를 활용한다.

**문제·해설 쪽**
- ANALOG(개념+기출 교재)의 해설 분리: 대학 공식 풀이와 사고 과정(왜 그렇게 생각했는가)을 나눈다. 기생기사(기출 해설)에서 "채점 기준 중심 해설"과 "사고 과정 해설"을 별도 층으로 두면 차별화된다.
- 여상진(정규반 교재)의 (다른 풀이)와 (참고) 코너: 대안 풀이와 점수 위험 알림을 분리한다.
- 우주설(학교별 대비 교재)의 단계별 연습(1~4단계): 같은 유형을 단계적으로 어렵게 편성해 계단을 만든다. 유유상종(유형별 N제)의 유형 안 배열에 적용한다.
- 소문항 연쇄에서 앞 결과를 뒤에서 쓰는 설계(대부분 교재 공통)를 해설에서 화살표로 표시해 주면 학생이 논리 흐름을 보기 쉽다.
- 여상진 모의논술(실전 모의)의 문항별 배점과 도움말: 백전불태(실전 모의논술)에서 시험 환경과 같게 만드는 데 유용하다.
- 우주설(학교별 대비 교재)의 "대학발표 예시답안" 표기와 제시문을 번호로 인용하는 답안 형식: 서술 형식의 모범으로 삼는다.
- SEMI(문제해결 기법서)의 풀이 속 기법 태그: 풀이를 읽으며 기법 이름을 익히게 하는 장치로 매우 효과적이다.

**편집·학습 설계**
- 쪽당 한 문항에 풀이 공간을 남기는 방식(여상진, 우주설): 학생이 직접 써 보게 한다.
- 단원과 난이도를 명시하는 표지와 목차, 쪽 하단의 현재 위치 표시.
- 출처 표기를 문항 제목줄에 통일하는 방식(연도, 대학, 계열, 시험 종류)과 배점 표기.

### 5.2 피할 단점

| 단점 | 어디서 보였나 | 우리 교재에서의 대응 |
|---|---|---|
| 난이도 표시 없음 | 거의 모든 시중 교재 | 문항마다 난이도를 표시하고 이유도 한 줄 적는다 |
| 하 난이도가 부족해 입문 계단이 없음 | 여상진 정규반(정규반 교재)은 하가 1~2문항 | 절차탁마(개념·연습)에 수능형 확인 문항과 기초 서술 문항을 둔다 |
| 해설이 책 뒤에 모여 대조가 번거로움 | 여상진 정규반(정규반 교재) | 문항과 해설을 같은 펼침면이나 QR로 연결하고, 별책 해설은 번호 대응표를 붙인다 |
| 손글씨 해설의 판독 어려움과 오기 | ANALOG 해설편(해설집) | 해설은 조판하되, 학생이 실제 쓸 분량이라는 점은 "답안 예시" 코너로 따로 보여 준다 |
| 해설이 약식이거나 일부 제시문만 쓰는 경우 | ANALOG 해설편(해설집) | 답안 예시는 모든 제시문을 어디에 쓰는지 표시한 완전 풀이로 만든다 |
| 해설 문항 번호 혼동(장별 중복 번호) | 여상진(정규반 교재) 해설편 | 문항 번호에 장 접두를 붙이거나 일련번호를 쓴다 |
| 오탈자와 계산 오류 | 여러 교재에서 DB 입력 때 의심 지점이 발견됨 | 교정 단계에서 모든 문항을 직접 풀어 정답을 검산하고, 정오표 계획을 둔다 |
| 개념 설명이 거의 없고 기출 나열 | 여상진 모의논술(실전 모의), 김기원 특강(특강 시험지), 서지현(개념+기출 교재)의 기출 위주 구간 | 모의 교재에도 각 문항이 어떤 개념 체크 항목과 연결되는지 표를 붙인다 |
| 출처가 아예 없거나 표기 방식이 제각각 | 여상진 모의논술(실전 모의), SEMI(문제해결 기법서) | 모든 문항에 출처 또는 "자체 제작"을 명시한다 |
| 한 소재 편중으로 학습 범위가 치우침 | 우주설(학교별 대비 교재)의 연세대 편향, 여상진 모의논술 회차별 단원 몰아주기 | 학교별 대비는 보조 장으로, 본 교재는 단원·유형 균형을 유지 |
| 올림피아드식 난이도 과다 | SEMI(문제해결 기법서) | 기법은 가져오되 논술 범위(교과서 + 제시문)로 수준을 맞춰 새 문항을 만든다 |
| 엄밀성 지도가 "감점 경고"에 그침 | 여러 정규반 교재(정규반 교재) | 어디까지 쓰면 만점인가를 채점 포인트 목록(필수 서술 / 있으면 좋은 서술 / 불필요)으로 구체화 |

### 5.3 차별화 포인트

**공통**
1. 난이도 표시 + 소요 시간 + 채점 포인트: 시중 교재 거의 전부에 없는 항목이다. 대학 채점 기준 공개 정보(가이드북 등)를 근거로 우리가 정리한다.
2. 풀이 2층 구조: 대학 방식 답안(시험지에 쓸 분량) + 사고 과정 해설(발상 경로). ANALOG는 이를 시도했지만 손글씨와 별책으로 흩어져 있다. 우리는 한 지면에서 연결한다.
3. 기법 태그 체계의 논술화: SEMI(문제해결 기법서)의 기법 태그 방식을 논술 용어(샌드위치, 평균값 정리 적용, 3항 부등식 세우기, 좌표 설정, 케이스 분류 등)로 만들어 모든 교재에 일관되게 쓴다. 한 문제에 붙은 태그로 유형 색인을 만든다.
4. 단원 융합과 교차 색인: 확통 + 미적분(급수·적분), 기하 + 미적분처럼 융합 문항이 늘어난다. 단원별 책이 아니라 개념 태그 색인(어떤 문항이 어떤 개념·기법을 쓰는가)을 부록으로 제공한다.
5. 서술 훈련: 쓴 답안을 스스로 점검하는 체크리스트(조건 누락, 경우 누락, 엄밀성 표현, 결론 문장)를 쪽마다 붙인다.

**교재별 적용안**

- **유유상종(유형별 N제)**
- 가져올 것: 서지현(개념+기출 교재)의 논제 형태 분류 + 형태별 전략 한 줄, 우주설(학교별 대비 교재)의 단계별 연습.
- 구성 제안: 유형 → 핵심 전략 한 줄 → 기초(하) → 표준(중) → 심화(상) 순서의 N제, 문항마다 난이도와 기법 태그.
- 차별화: 같은 유형을 다른 단원에서 비교하는 "유형 횡단" 색인(예: 샌드위치 정리가 극한, 급수, 정적분에서 쓰이는 방식 비교).

- **백전불태(실전 모의논술)**
- 가져올 것: 여상진 모의논술(실전 모의)의 시험지 형식, 문항별 배점, 도움말.
- 피할 것: 회차별 한 단원 몰아주기. 실제 시험처럼 단원이 섞이도록 구성한다.
- 차별화: 배점 + 시간 배분 안내, 채점 기준표, 학생 자기 채점표, 대학별(계열별) 모의 구분. 해설은 "대학 방식 답안"과 "자주 나오는 감점 답안" 대비로 구성.

- **절차탁마(개념·연습)**
- 가져올 것: 여상진(정규반 교재)의 개요 박스와 STEP, 개념 → 예제 → 실전 순서, ANALOG(개념+기출 교재)의 개념 중간 확인 문항(ex)과 직접 증명 연습.
- 차별화: 개념마다 "논술에서 증명을 요구받는 지점" 표시, 하 난이도 확인 문항으로 입문 계단 제공, 장 끝에 자기 점검표.

- **임기응변(신유형)**
- 가져올 것: SEMI(문제해결 기법서)의 기법 체계(관찰과 실험, 변형과 비약), 우주설(학교별 대비 교재)의 함수방정식·정수론·증명 논제 흐름.
- 목적: 처음 보는 유형에서 시작 방법을 정하는 훈련. "막혔을 때 체크리스트"(작은 경우 해 보기, 극단 경우, 문자 일반화, 대칭, 조건 재독)를 장마다 둔다.
- 차별화: 신유형 문항은 기출 변형이 아닌 자체 제작을 원칙으로 하고, 제시문 구조(정의 도입형, 증명 완성형, 알고리즘형)별로 접근 틀을 제공한다.

- **기생기사(기출 해설)**
- 가져올 것: ANALOG(개념+기출 교재)의 4단 해설(대학 풀이 → 사고 과정 → 손글씨 → Tip), 우주설(학교별 대비 교재)의 대학 예시답안 표기와 제시문 인용 형식.
- 차별화: 대학 공식 답안의 채점 포인트를 분해한 표(점수가 걸린 서술), 소문항 연결 지도, 학생 답안에서 흔한 감점 사례. 출제 경향은 연도별 표로 정리한다.
- 주의: 대학 공개 해설을 전재하지 않고 요약 + 출처 안내.

- **속전속결(성격 미확인, 속도 훈련용으로 가정)**
- 가져올 것: ANALOG 확통(개념+기출 교재)의 "효율성과 정확성" 원칙, 여상진(정규반 교재)의 계산량 줄이기 요령.
- 구성 제안: 제한 시간 안에 서술하는 단문 세트, 계산 단축 기법(대칭성 적분, 좌표 설정, 판별식 대신 거리), 시간 기록란.
- 확인 필요: 정확한 성격(종류)이 정해지면 위 제안을 조정한다.

- **일타쌍피(성격 미확인, 한 문제로 두 가지를 익히는 용도로 가정)**
- 가져올 것: 여상진(정규반 교재)의 한 문제 두 풀이 병기, ANALOG(개념+기출 교재)의 소문항 연쇄 재사용, SEMI(문제해결 기법서)의 "두 가지 관점에서 세기".
- 구성 제안: 같은 문제를 두 단원 관점(미분과 부등식, 기하와 벡터 등)으로 푸는 쌍 풀이, 어느 풀이가 서술에 유리한지 비교표.
- 확인 필요: 정확한 성격(종류)이 정해지면 조정한다.

### 5.4 집필 전 체크리스트

1. 각 교재의 종류와 대상 학생 수준을 정한다(입문, 표준, 심화).
2. 장 구성 틀(개요 → 개념 → 확인 → 예제 → 실전 → 점검표)을 공통으로 쓰되, 박스 이름은 우리 용어로 새로 짓는다.
3. 문항 풀(대학 공개 기출, 자체 제작)과 각 문항의 출처·난이도·기법 태그·개념 태그를 먼저 표로 만든다.
4. 해설은 2층(답안 예시, 사고 과정)으로 쓰고, 채점 포인트를 따로 표시한다.
5. 모든 정답과 수식을 두 사람이 교차 검산한다.
6. 타사 문장과 우연히 겹치는 표현이 없는지 최종 점검한다.
