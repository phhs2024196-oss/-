# 교재 DB 입력 지시서 (서브에이전트 공통)

너는 '논술의 시대' 교재 참고 DB(TB)에 시중 수리논술 교재의 **모든 문항**(개념 확인·예제·연습·실전·기출 인용 문항 전부)을 입력하고, 개념 설명은 요약 노트로 남긴다. 한국어. git 금지.

## 입력
- 쪽 이미지: `/tmp/claude-0/tb/<BOOK>/p-NNN.png` (120dpi, NNN은 PDF 쪽 번호, 자릿수는 폴더에 있는 대로). 이미지 Read로 본다. 작아서 안 보이는 부분만 `pdftoppm -r 200 -f N -l N -png "<pdf>" /tmp/claude-0/tb/zoom/x` 후 crop(PIL)해서 본다.
- 텍스트층이 있는 책은 `pdftotext -f N -l N "<pdf>" -` 로 한글만 참고(수식은 깨져 있으니 이미지 기준).

## 임시 파일
임시 파일은 반드시 자기 전용 폴더 `/tmp/claude-0/tb/work/<BOOK>-<시작쪽>/` 에만 만든다(다른 에이전트와 공유 금지, 남의 raw 파일 덮어쓰기 금지).

## 출력 (2개 파일, 담당 쪽 범위만)
1) `/mnt/project-files/textbook-db/raw/<BOOK>/p<시작>-<끝>.yaml` — 아래 형식의 항목 리스트. 5쪽 처리할 때마다 파일에 덧붙여 저장(중간 저장).
2) `/mnt/project-files/textbook-db/notes/<BOOK>/p<시작>-<끝>.md` — 이 범위의 개념 설명·Tip·풀이 전략 요약(정의·정리·공식·자주 나오는 논증 패턴·저자의 강조점, 원문 길게 베끼지 말고 요점), 그리고 '양식' 메모(페이지 구성 요소: 박스 이름, 코너 이름, 난이도 표시, 출처 표기 방식 등). 30줄 이내.

```yaml
- id: <BOOK>-p<쪽3자리>-<그 쪽 안 순번>      # 예: ANA-GEO-p045-2
  book: <BOOK>
  page: 45                 # PDF 쪽 번호
  printed_page: 44         # 인쇄 쪽 번호(보이면, 없으면 null)
  chapter: 'Theme 02 | 평면벡터'   # 원문 표기 그대로
  section: '4) 위치벡터'           # 소단원(있으면)
  role: 예제                # 개념확인 | 예제 | 연습 | 실전 | 기출 | 모의 | 해설   (책 고유 이름은 label에)
  label: 'Example 3'       # 책에 적힌 문항 번호·이름 그대로 (예: '예제 23-1', '실전문제 5', '[문제 2]')
  cited_source: '2020학년도 연세대 자연계열 논술'   # 문항 옆 출처 표기(없으면 null). 원문 그대로
  stem: |
    (문항 원문 그대로. 제시문·발문·소문항·조건·배점 전부. 수식은 $...$ LaTeX, $ 안쪽 공백 없이)
    (그림은 [그림: 설명], 표는 마크다운 표 대신 줄글로, 모르는 글자는 [판독확인: 이유])
  points: null             # 배점 있으면 숫자 또는 '(1) 10, (2) 15'
  answer: null             # 같은 쪽/범위에 답이 있으면 최종 답만 짧게. 없으면 null
  solution_summary: null   # 해설이 범위 안에 있으면 핵심 흐름 2~4줄(원문 전체 복사 금지)
  subject: 미적분           # 수학Ⅰ | 수학Ⅱ | 미적분 | 확률과 통계 | 기하 | 수학(상·하) | 기타
  unit_path: [미적분, 미분법, 도함수의 활용]   # 2015 교육과정 기준 3~4단
  concepts: [평균값 정리, 볼록성]              # 핵심 개념 2~5개
  skills: [부등식 증명, 경우 나누기]           # 풀이 기술·논증 패턴
  level: 중                 # 하 | 중 | 상 | 최상 (판단)
  flags: []                 # 판독확인, 그림중요, 답없음 등
```
- **해설 쪽**(책 뒤 해설·손글씨해설편·별도 해설 파일)은 role: 해설, label 에 대응 문항 번호를 원문대로, stem 은 비우고(null) `answer`와 `solution_summary`만 채운다. 나중에 스크립트가 label로 문항과 합친다. `solves_book:` 에 문항이 실린 BOOK 코드를 적는다(같은 책이면 생략).
- 개념 설명만 있는 쪽은 YAML 항목 없이 notes에만 쓴다. 표지·머리말·목차는 notes 첫 줄에 '목차' 구조만(장·절 제목) 기록.
- 문항 원문은 **한 글자씩 정확히**. 요약·생략·말바꿈 금지. 수식이 길어도 전부.
- 한 쪽에 걸쳐 이어지는 문항은 시작 쪽 id로 하나만.

## 마치면
YAML이 파싱되는지 `python3 -c "import yaml,sys;d=yaml.safe_load(open(sys.argv[1]));print(len(d))" <파일>` 로 확인.
보고는 3줄: 항목 수(문항/해설) · [판독확인] 개수 · 특이사항(범위 끝에서 잘린 문항 등).
