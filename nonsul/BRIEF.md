# 유형별 수리논술 N제 — 공통 제작 지침 (숭실·동국·세종)

각 작업자는 배정된 **유형 2개 × 유형당 10문항**을 설계·제작·검산한다. 이 문서의 규칙이 전부 적용된다.

## 1. 난이도 등급 L (막히는 지점 수로 판정, 소재가 어려워 보인다고 올리지 말 것)

| L | 기준 |
|---|---|
| L3 | 수능 쉬운 4점 = 세 학교 실전 평균 |
| L4 | 수능 준킬러 = 실전에서 가장 어려운 문항. 발상 1개로 끝남 |
| L5 | 수능 킬러급: 경우 분류 / 조건 해석 / 2단계 이상 구성 중 하나가 필수 |
| L6 | 보조함수·불변량·귀류 중 하나를 수험생이 스스로 설정 (힌트 소문항 없이 방향 설정) |
| L7 | 교육과정 밖 — 금지 (로피탈, 테일러 전개, 편미분, 행렬, 복소평면, 이중적분 등 금지) |

유형당 10문항 분포: **L4 2문항 → L5 6문항 → L6 2문항**, 쉬운 것부터 배열(실력 향상용 사다리).

## 2. 형식 12종 (문항마다 하나만 라벨)

추론 / 분류 / 이중세기 / 최적2단 / 구성 / 점화 / 불변량 / 일반화 / 존재 / 귀류 / 귀납구조 / 전수

- 한 유형 10문항 안에서 **같은 형식은 최대 3번**, 형식 종류는 **4종 이상** 쓸 것(단조로움 방지).
- 같은 유형 안에서 함수·도형·수치 설정이 서로 닮지 않게. "숫자만 바꾼 문항" 금지.

## 3. 학교별 규격

| 학교 | 문항 형태 | 배점 | 범위 |
|---|---|---|---|
| 숭실(S) | 제시문(교과서 정리 1~2개, 출처 표기) + 논제 1개(필요시 소문항 2개) | 25점 | 수학·수Ⅰ·수Ⅱ·미적분 (확통·기하 제외) |

## 설계도

| ID | L | 형식 | 열쇠 | 정답 | 막힘 | 대표 오답(값) |

수식 표기 규칙(자동 조판되므로 엄수):
- 인라인 `$...$`, 별행 `$$...$$`. `$` 바로 안쪽에 공백 금지(`$ x $` ✗, `$x$` ✓). `\(`, `\[` 금지.
- 표(`|`) 안의 수식에는 `|`를 쓰지 말고 `\lvert x\rvert`, `\mid` 사용.
- KaTeX가 지원하는 명령만 사용(`\dfrac`, `\displaystyle`, `\begin{cases}` 가능. `\tag`, `\label`, tikz, 그림 파일 금지). 그림이 필요한 상황은 좌표·조건을 글로 완전히 서술.
- 한국 교과서 용어·문체("~을 구하시오", "~임을 보이시오").

### 5-2. `verify_Txx.py` — sympy 검산 스크립트

- `python3 verify_Txx.py` 로 실행. 문항마다 함수 하나(`def p01(): ...`).
- **정답을 하드코딩해서 자기 자신과 비교하지 말 것.** 문제의 설정(S)으로부터 sympy(`integrate`, `solve`, `limit`, `summation`, `Rational`, `diff` 등)나 전수 열거(`itertools`)로 **독립적으로 다시 계산**하고, 그 결과가 md의 정답과 같은지 `assert` 수준으로 비교한다. 기호 계산이 안 되면 `mpmath`/`scipy` 고정밀 수치(상대오차 1e-9)로 닫힌 식과 비교.
- 동국·세종은 소문항 (1)(2)(3) 값을 각각 검산.
- 증명 소문항은 "명제를 수치로 반례 탐색"(예: 부등식을 격자 1000점에서 확인, 점화식 명제를 n=1..200 확인, 항등식을 무작위 20점에서 확인)으로 검산하고 `[증명-수치확인]`으로 표시.
- 가능하면 대표 오답 값도 "그 실수를 했을 때의 계산"으로 재현.
- 출력 형식: 문항마다 `S01-01 PASS  <확인한 내용 한 줄>` 또는 `FAIL`. 마지막 줄 `SUMMARY T01: 10/10 PASS`. FAIL 이 하나라도 있으면 `sys.exit(1)`.
- 검산에서 정답이 md와 다르면 **문항(md)을 고친 뒤** 모범답안·채점표·설계도 표까지 일관되게 수정. 정답이 지저분하면(근호 3중, 닫힌 식 없음) 설정을 바꿔 깔끔한 값이 나오게 할 것. 전부 PASS 할 때까지 반복.
